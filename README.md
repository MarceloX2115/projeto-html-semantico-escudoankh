# Wiki Terraria - Escudo de Ankh 🛡️

Este projeto consiste no desenvolvimento de uma página web informativa focada na **Arquitetura da Informação** e no uso rigoroso de **tags semânticas** da W3C. O tema escolhido foi a árvore de criação do item *Ankh Shield* (Escudo de Ankh) do jogo Terraria.

## 📌 Objetivo do Projeto
Demonstrar a estruturação de conteúdo web utilizando exclusivamente HTML5, garantindo que a hierarquia de informações seja clara tanto para usuários quanto para motores de busca e tecnologias assistivas.

## 🛠️ Tecnologias Utilizadas
* **HTML5 Semântico:** Uso de tags estruturais para definir o significado de cada seção.
* **Arquitetura de Navegação:** Implementação de âncoras internas para facilitar a experiência do usuário.
* **Mídias Externas:** Incorporação de vídeos e imagens para suporte visual.

## 🏗️ Estrutura do Documento
O site foi construído seguindo os requisitos técnicos abaixo:
- **Tags Estruturais:** `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>` e `<footer>`.
- **Hierarquia de Títulos:** Organização lógica de `<h1>` até `<h4>`.
- **Elementos de Texto:** Parágrafos, listas ordenadas/não ordenadas e citações (`blockquote`).
- **Dados Tabulares:** Tabela completa com `<thead>`, `<tbody>`, `<tr>`, `<th>` e `<td>`.
- **Navegação:** Links internos (âncoras) e links externos com `target="_blank"`.

## 📁 Como rodar o projeto
1. Clone este repositório ou baixe os arquivos.
2. Certifique-se de que a imagem `escudo.png` está na mesma pasta que o arquivo `index.html`.
3. Abra o arquivo `index.html` em qualquer navegador moderno.

## 🎮 Sobre o Tema
O **Escudo de Ankh** é um dos acessórios mais complexos de Terraria. A página detalha todos os 11 materiais necessários, suas respectivas imunidades e um guia visual em vídeo para auxiliar o jogador na jornada de craft.
